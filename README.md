# Emmanuel Kibet — Portfolio

Personal portfolio website for **Emmanuel Kibet**, a frontend developer and UI/UX designer. The site presents background, skills, education, featured work, and a way to get in touch.

**Live site (GitHub Pages):** [https://emmanuzi.github.io/Web_Portfolio/](https://emmanuzi.github.io/Web_Portfolio/)

## About

This is a single-page portfolio built with HTML, CSS, and JavaScript. It is designed as a visual introduction to my work: clean layouts, animated sections, and a dark/light theme.

I am currently studying Computer Science at Pwani University and completed a full-stack web development bootcamp at Modcom Institute. I focus on modern web technologies and turning ideas into simple, usable interfaces.

## What’s on the site

- **Home** — Name and role with a typewriter-style intro
- **About** — Short bio and profile photo
- **Skills** — Languages, frameworks, and skill breakdowns for frontend, backend, and DevOps
- **Education** — Academic background and a CV download
- **Interests** — AI, mobile development, cloud, cybersecurity, game development, and open source
- **Projects** — Featured work such as an e-commerce platform, a task management app, and a weather dashboard
- **Contact** — Form to send a message

## Features

- Animated loading screen
- Custom magnetic cursor
- Dark and light theme toggle
- Dot navigation between sections
- Morphing background and glass-style cards
- Responsive layout for desktop and mobile

## Tech stack

- HTML5
- CSS3
- JavaScript
- [Google Fonts](https://fonts.google.com/) (Poppins)
- [Font Awesome](https://fontawesome.com/)

## Getting started

No build step or package manager is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/Emmanuzi/Web_Portfolio.git
   cd Web_Portfolio
   ```

2. Open `index.html` in a browser, or serve the folder with a local static server.

## Project structure

```text
Web_Portfolio/
├── index.html      # Page markup and content
├── style.css       # Layout, theme, and animations
├── script.js       # Loading screen, cursor, navigation, and interactions
└── assets/         # Profile image and CV
```
